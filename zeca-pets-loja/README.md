# Zeca Pets — Loja

Site de vendas de produtos pet (HTML, CSS e JavaScript puros, sem dependências).
Abra `index.html` no navegador.

## Configuração (app.js)
- `WHATSAPP`: número da loja para receber os pedidos
- `PRODUCTS`: lista de produtos (nome, categoria, pets, preço)
- Cupom de exemplo: `BEMVINDO10`; frete grátis acima de R$ 150
